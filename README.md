A two-sentence horror story, written by a small deterministic Node program. A narrator keeps a nursery ready — knitting tiny socks, leaving the lamp burning low — for a baby who was never there, until something in the empty house starts taking what is made for it.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes the story to `/tmp/out/entry.txt` (exactly two sentences, under 400 characters).
